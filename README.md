6. Что делает каждый раздел?
Входящие
Сюда попадают все новые невыполненные задачи.

Здесь пользователь:

добавляет задачу
видит список задач
удаляет задачи
отмечает задачи выполненными
Сегодня
Сюда попадают задачи, у которых дедлайн стоит на сегодняшнюю дату.

Планы
Сюда попадают задачи с будущей датой.

Календарь
Здесь задачи группируются по датам.

То есть пользователь видит, какие задачи стоят на какой день.

Проекты
Здесь задачи группируются по тегам.

Например:

Учёба
Работа
Личное
Архив
Сюда попадают выполненные задачи.

Если пользователь нажал кнопку ✓, задача считается завершённой и переходит в архив.

7. Как работает сохранение задач?
В проекте используется два способа сохранения:

localStorage
Это память браузера.

Она нужна для того, чтобы задачи не пропадали после обновления страницы.

JSONBin
Это облачное хранилище.

Оно нужно для того, чтобы хранить задачи не только в браузере, но и в интернете.

Если JSONBin временно не работает, сайт всё равно может использовать localStorage.

Шаг 2

Шаг 3

Шаг 7
Чтобы завершить задачу, нажать кнопку ✓.

Шаг 8
Чтобы удалить задачу, нажать кнопку Удалить.
